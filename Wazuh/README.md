# Wazuh

## Overview

This section documents the deployment and use of **Wazuh** within the **TheCoinSociety** home lab.

Wazuh was implemented as the central security monitoring platform for collecting and analysing security events from systems within the lab environment. The project covers the initial deployment and configuration of Wazuh, endpoint integration, and practical security testing performed after implementation.

## Objectives

The Wazuh implementation was used to:

- Establish centralised security monitoring within the lab.
- Collect security events from monitored endpoints.
- Gain practical experience deploying and managing a SIEM platform.
- Perform and document security monitoring and detection use cases.
- Validate detections through controlled testing.
