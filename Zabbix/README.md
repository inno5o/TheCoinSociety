# Zabbix Infrastructure Monitoring

## Project Overview

This project documents the implementation of **Zabbix** as the infrastructure monitoring platform for **TheCoinSociety**, a simulated enterprise network built in a GNS3/VMware lab environment.

Zabbix was deployed on an **Ubuntu Server** and integrated into the existing TheCoinSociety infrastructure to provide centralized visibility into the availability, health, and performance of networked systems.

The implementation focused on building a functional monitoring environment rather than simply installing the platform. Systems were added to Zabbix, monitoring was configured, and collected data was verified through the Zabbix dashboard.

## Objectives

- Deploy and configure a centralized Zabbix monitoring server.
- Integrate Zabbix into the existing TheCoinSociety network.
- Monitor infrastructure hosts and services.
- Collect system and performance metrics.
- Configure monitoring triggers and alerts where required.
- Verify successful communication and data collection from monitored systems.
- Provide centralized infrastructure visibility through the Zabbix web interface.

## Lab Environment

The implementation forms part of the larger **TheCoinSociety enterprise lab**, built using:

- GNS3 VM
- VMware
- Ubuntu Server
- Virtualized servers and network infrastructure
- TheCoinSociety internal network

## Project Scope

This documentation focuses on the practical implementation and verification of Zabbix within the lab.

Detailed experimentation, monitoring scenarios, failure simulations, alert testing, and other advanced exercises are documented separately from the core implementation.
